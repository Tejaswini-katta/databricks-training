# SQL Practice - Day 3

This folder contains SQL practice for Day 3 focused on join operations and unmatched row analysis in relational tables.[1]
It includes the starter schema, query solutions, and output results for a SQL joins assignment based on an online learning platform dataset.[1]

## Topics Covered

- LEFT JOIN
- RIGHT JOIN
- FULL OUTER JOIN
- Unmatched row identification
- Multi-table join reporting
- CROSS JOIN basics

## Files

- `joins_starter.sql` - Schema creation and sample data insertion script
- `queries.sql` - Solutions for the joins assignment questions
- `outputs.txt` - Query outputs generated after execution

## Learning Focus

This day focused on understanding how different join types behave when matching and non-matching rows exist between tables.
Special attention was given to finding missing relationships such as students without enrollments, courses without instructors, and full join reporting across related tables.

## Notes

- The dataset models a simple online learning platform using `students`, `courses`, `enrollments`, and `instructors`.
- The assignment includes 10 join-based questions plus one bonus challenge.
- FULL OUTER JOIN is part of the exercise focus, along with practical handling of unmatched records.
