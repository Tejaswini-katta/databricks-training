
# Week 1 SQL Practice

This week I practiced the fundamentals of SQL using a structured employee database and later expanded into joins, subqueries, and mixed query patterns. The work was organized day-wise so I could build from basic filtering to more advanced analytical queries.

## Week 1 Summary

- Day 1: Basic SQL queries, string matching, date filtering, aggregate functions, GROUP BY, HAVING, ORDER BY, and joins.
- Day 2: Employee-focused query practice with additional filtering and formatting logic.
- Day 3: Join-based exercises covering INNER JOIN, LEFT JOIN, subqueries, and department/project relationships.
- Day 4: Advanced SQL practice with window functions and CTEs.

## Day 1 Work

I started with core SELECT queries, filtering rows using WHERE, and learning how to retrieve specific columns from tables such as Employee and Department. I then practiced string-based conditions using LIKE, CHAR_LENGTH, and SUBSTR to find names that matched patterns. After that, I worked on date-based queries using YEAR, MONTH, and date comparisons. I also practiced aggregate functions like SUM, AVG, MIN, MAX, COUNT, followed by GROUP BY and HAVING to analyze department-wise salary and employee counts.

## Day 2 Work

On day 2, I worked on queries based on an employee dataset, focusing on null handling and regular SQL practice. The queries covered extracting records, conditional filtering, and working with employee-related data fields in a more application-like setup. This helped strengthen my understanding of how SQL behaves with real table structures and practical scenarios.

## Day 3 Work

On day 3, I practiced SQL joins using Employee, Department, and Project tables. I wrote queries using INNER JOIN and LEFT JOIN to connect related data, identify employees without projects, and find departments without employees. I also used subqueries to answer nested questions such as employees sharing the same department as a specific person, employees earning above average salary, and departments with the highest salary metrics.

## Day 4 Work

On day 4, I moved into advanced SQL topics such as window functions and CTEs. I practiced ranking, row numbering, partitioning, cumulative calculations, and recursive CTE concepts. These exercises helped me understand how to solve reporting and analytical problems more efficiently in SQL.

## Skills Covered

- SELECT, WHERE, ORDER BY.
- LIKE, SUBSTR, CHAR_LENGTH.
- DATE functions such as YEAR, MONTH, and CURRENT_DATE-based filtering.
- Aggregate functions and GROUP BY.
- HAVING for grouped conditions.
- INNER JOIN and LEFT JOIN.
- Subqueries and correlated subqueries.
- Window functions and CTEs.

## Outcome

By the end of Week 1, I had a solid foundation in SQL querying, filtering, joining tables, grouping data, and solving both basic and intermediate-level database problems. The practice also prepared me for more advanced topics like analytical SQL, reporting, and recursive query patterns.
